# Audit reklam Tři Mistři
Sdílený přehled auditu z 12. října 2026.

Otevřít: https://romankaxo.github.io/trimistri-navrh/audit-reklam/

Stránka obsahuje rozbor aukcí, reklam, klíčových slov, vstupních stránek a návrh
testu nabídek. Lze stáhnout 19stránkové PDF a CSV přílohy. Hledání a rozpočtový
kalkulátor fungují v prohlížeči a nijak nemění nastavení reklamního účtu.

Zveřejněné údaje jsou datový snímek uvedeného období, nikoli průběžné měření.
Hodnocení Vynikající v editoru se nesmí zaměnit za dosažené skóre slov nebo pozice.

Interní exporty, identifikátor reklamního účtu, technické zálohy a zdrojový generátor
nejsou součástí publikované složky. Web je veřejný, označený noindex.

Pro lokální otevření ponechte index.html vedle PDF, CSV a adresáře screenshots.
Celý tento souborový balíček je v trimistri-audit.zip.
